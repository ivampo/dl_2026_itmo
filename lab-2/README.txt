ДЗ-2. Детекция: объекты на картинках (YOLO) или сущности в тексте (NER)

Выберите ОДИН вариант и откройте его ноутбук, условия, критерии, открытые тесты и места для ответов там:
- hw2_cv.ipynb - детекция объектов на YOLO (ultralytics), продолжение семинара 5-6
- hw2_nlp.ipynb - NER, т.е. та же детекция, только в тексте: предобученный энкодер с Hugging Face (token classification)

Номера задач, баллы и срок в обоих вариантах одинаковые. Сдаете один ноутбук, второй вариант баллов не добавляет

Как варианты соответствуют друг другу
- бокс <-> спан
- класс <-> тип сущности
- фон <-> тег O
- VOC/COCO -> YOLO-формат <-> слова/спаны -> BIO-теги под сабворды
- mAP по IoU <-> F1 по сущностям (seqeval)
- ошибка локализации <-> ошибка границы спана

Что внутри (одинаково в обоих вариантах)
1. Модель: скачать с зафиксированной версией и объяснить выбор (1.1), расписать архитектуру по блокам (1.2)
2. Данные: найти свой датасет (2.1), привести разметку к нужному формату и проверить конвертацию (2.2)
3. Бейзлайн до дообучения (3.1)
4. Дообучение и метрики (4.1, 4.2)
5. Разбор ошибок, одна абляция, выводы (5.1-5.3)
6*. Бонусы на выбор через BONUS_TASKS (6.1-6.5), за бонусы до +4
Итого 20 баллов + до 4 бонусных

Запуск
1. Colab или Kaggle с GPU T4 (подойдет и своя видеокарта)
   - Colab: Runtime -> Change runtime type -> T4 GPU
   - Kaggle: в настройках ноутбука Accelerator = GPU T4 x2 и включенный Internet (для GPU и интернета Kaggle просит подтвердить телефон)
2. Загрузите ноутбук своего варианта:
   - CV: рядом положите requirements_cv.txt, установка в ноутбуке: %pip install -q -r requirements_cv.txt. Первая ячейка сама ставит ultralytics, если его нет
   - NLP: зависимости ставит первая ячейка ноутбука (пины те же, что в requirements_nlp.txt), перезапуск сессии не нужен. Строки ERROR от pip про bigframes / cudf на Kaggle и предупреждение про HF_TOKEN безвредны, токены не нужны
3. Сначала прогоните ноутбук с FAST_MODE = True: это проверка кода на маленьком бюджете, на T4 до 5 мин
4. Финальный прогон с FAST_MODE = False, на T4 до ~1 ч. На Kaggle его удобно запускать через Save Version -> Save & Run All, он идет в фоне. В Colab не оставляйте вкладку надолго без дела, сессию может отключить
5. Модели и датасеты ноутбук скачивает сам, в архив они не входят, нужен интернет

Правила
- датасет ищете сами, подсказки где искать - в задаче 2.1. CV: открытая лицензия, от ~150 картинок, не PennFudan (он был на семинаре) и не учебные coco8/coco128. NLP: любой подходящий по языку к вашей модели, кроме WikiANN ru (на нем в шаблоне показан пример формата), другие языки WikiANN можно
- только открытые модели и данные (модели с HF Hub или из ultralytics), лицензию указывайте
- свой код обязателен в 1.2 (подсчет параметров по блокам), 2.2 (конвертация и тест), 3.1 (тривиальный бейзлайн), 5.1 (разбор ошибок). Для обучения и стандартных метрик можно ultralytics / transformers (Trainer) / seqeval
- можно пользоваться документацией, материалами курса и кодом семинаров (в CV, например, кодом YOLO и to_yolo с семинара 5-6), источник указывайте в ячейке «Сведения о сдаче»
- API-ключи и токены (Roboflow, HF, Kaggle) в ноутбук не вписывайте: репозиторий публичный
- индивидуально
